# Submission descriptions — copy & paste

Each file below contains the text for one week's **“Write description for the
report”** box. Every description is **more than 200 words**, as required.

Each week also needs a **Word document (.doc / .docx)** containing:
the same description plus screenshots of the page. The `SUBMISSION-CHECKLIST.md`
in the root folder lists exactly what to upload for each week.

| Week | Description file | Required upload |
| --- | --- | --- |
| 1 | `week-1-submission.md` | `index.html`, `css/`, `js/` + Word report |
| 2 | `week-2-submission.md` | **one ZIP** with all source files + Word report |
| 3 | `week-3-submission.md` | **one ZIP** incl. the audit report + Word report |
| 4 | `week-4-submission.md` | **one ZIP** with the project + performance report |
| 5 | `week-5-submission.md` | project + JSON data + documentation (200+ words) |

> The **GitHub URL field can be left blank** — the task description says a
> technical GitHub URL will be ignored, and none of these projects are
> hosted repositories. Submit the files instead.
