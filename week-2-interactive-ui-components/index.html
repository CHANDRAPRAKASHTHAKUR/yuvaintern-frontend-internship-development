Interactive UI components, vanilla JavaScript

Eight production-ready components. Each one is a small ES5-compatible class with no dependencies, full ARIA semantics and complete keyboard support. Resize the window to see the layout adapt from a two-column grid to a single column.

0 dependencies ~700 lines of JS WCAG 2.1 AA patterns

01 Modal dialog

Opens in the top layer with a translucent backdrop. Focus is trapped inside, Esc closes it, the background is marked inert, and focus returns to the trigger button on close.

Programmatic API: NovaUI.modal.open('demo-modal') · NovaUI.modal.close() 

document.querySelectorAll('[data-modal-open]').forEach(btn => {
  btn.addEventListener('click', () => NovaUI.modal.open(btn.dataset.modalOpen));
});

02 Accordion

A single-expandible accordion. Headers are real <button> elements with aria-expanded and aria-controls; panels animate height without breaking keyboard order.

The panel is measured once with scrollHeight and then animated from 0 to that pixel value using a CSS custom property. After the transition ends, the inline height is removed so the panel can reflow freely when the window resizes.

Yes. Toggle the “Allow multiple open panels” control below — it sets data-accordion-multi to true and the accordion stops closing its siblings.

Headings wrap the triggers so screen-reader users can navigate by heading and jump straight to a question. Each panel is a labelled region, which means it is reachable in the landmarks list and announces its own title.

03 Tabs

Implements the WAI-ARIA authoring practices for tabs: a roving tabindex, ←/→ to move, Home/End to jump, automatic activation, and panels wired with aria-labelledby / aria-controls.

04 Dropdown menu

An ARIA menu with a menuitem list, roving focus, type-ahead, Esc to dismiss, and arrow keys to wrap around.

05 Switch & checkbox

A toggle built on role="switch" with aria-checked, operable with Space or Enter and a 200 ms thumb animation.

Switch state is announced by the screen reader through aria-checked.

06 Range slider

A custom range input with a filled track, a live value output and full keyboard support (arrows, Page Up/Page Down, Home/End).

07 Tooltip

Shown on hover and focus, wired with aria-describedby, dismissed with Esc, and positioned above the trigger unless there is no room.

08 Toast notifications

Stacked, auto-dismissing messages rendered into an aria-live="polite" region so they are announced without stealing focus. Hovering pauses the timer.

09 Progress & rating

A determinate progressbar animated by JavaScript, and a star rating widget that is fully operable with arrow keys.

Keyboard support cheat sheet

Inside this dialog, Tab and Shift+Tab cycle through the focusable elements and never escape the dialog.

  • EscClose the dialog and return focus to the trigger
  • TabMove to the next control
  • EnterActivate the focused button

Try it: press Tab a few times — the focus will loop back to the close button.
